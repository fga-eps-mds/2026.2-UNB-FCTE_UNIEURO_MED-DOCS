# Modelo de Ata de Reunião

Este documento define o padrão que a equipe adota para registrar as reuniões do
projeto. Toda ata deve ser criada a partir dele, preservando a ordem e os títulos
das seções.

## Convenções

**Nomenclatura do arquivo:** `Ata-NN-EPS-AAAA-MM-DD[-PO].md`, onde `NN` é o número
sequencial da ata e o sufixo `-PO` identifica as reuniões realizadas com a presença
do *Product Owner* ou do cliente. Reuniões internas da equipe não levam o sufixo.

**Presença:** a coluna *Presente* é preenchida com ✓ para quem participou e ✗ para
quem não participou. Quando a apuração for feita a partir da transcrição automática
do Teams, isso deve ser declarado na nota abaixo da tabela, já que a transcrição
registra apenas quem falou.

**Histórico de versão:** toda alteração posterior à criação da ata gera uma nova
linha na tabela de histórico, com autor e revisor identificados por link para o
perfil do GitHub.
