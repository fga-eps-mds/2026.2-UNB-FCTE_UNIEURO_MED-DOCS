# Equipe

Esta página reúne os integrantes da equipe responsável pelo projeto MED, além de uma visão geral das ferramentas e canais utilizados no dia a dia, desde comunicação até gestão de tarefas e design.

## Comunicação

| Canal | Uso | Participantes |
|---|---|---|
| Discord | Alinhamento com o Product Owner: dúvidas sobre o produto, validação de escopo e reuniões de review | Equipe e PO |
| WhatsApp | Comunicação do dia a dia da equipe: avisos, organização das dailies e combinados rápidos | Equipe |
| GitHub | Discussão técnica em issues e pull requests | Equipe |
